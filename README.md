# Cadeau-inator

Verlanglijst met afstrepen, in LEDJOCKEY-stijl.

- Live: https://jimmyhonderd.github.io/Cadeau-inator/#jimmy
- Lijsten: `lijsten/<id>.json`, overzicht in `lijsten/index.json`
- Afstrepen: Cloudflare Worker `cadeau-inator` (code op branch `cadeau-worker` in Jimmyhonderd/Vwab-arena). Die bewaart alleen wat er is afgestreept.
- Verrassingsmodus: wie aangeeft de eigenaar te zijn, ziet geen afstrepingen.
